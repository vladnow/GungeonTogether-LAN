# Gungeon Together LAN

[English](https://github.com/vladnow/GungeonTogether-LAN)

Экспериментальный кооператив для **двух игроков в Enter the Gungeon** по локальной сети или через Radmin VPN. Подключение — **хост/клиент по IPv4**. Хост выполняет штатную кооперативную симуляцию игры; клиент управляет Культистом и отображает переданные объекты средствами своей копии игры. У игроков общий вид камеры хоста.

**Версия 0.2.2 — ранняя альфа.** Полный забег, все боссы и предметы, а также сторонние сборки модов не проверены. Отображение, звук и часть взаимодействий на клиенте требуют доработки.

## Требования

- Два ПК с Windows, одинаковыми файлами игры и одной версией мода. Проверенная версия игры — Steam **2.1.9**.
- **BepInExPack EtG 5.4.2101** / BepInEx 5.
- Общая локальная сеть либо подключение к одной сети Radmin VPN. Radmin VPN устанавливается отдельно.
- Для первого подключения используйте только этот мод и его загрузчик. Другие сочетания модов не проверены.

## Установка

Готовые сборки размещаются в разделе [Releases](https://github.com/vladnow/GungeonTogether-LAN/releases). Кнопка GitHub **Code → Download ZIP** скачивает исходники, а не установочный пакет.

### ZIP для менеджера модов

1. Создайте чистый профиль Enter the Gungeon в Thunderstore Mod Manager или r2modman.
2. Установите в него **BepInExPack EtG 5.4.2101**.
3. Импортируйте архив релиза `GungeonTogether_LAN-0.2.2-Thunderstore.zip` через **Settings → Import local mod** либо установите пакет из каталога менеджера, если он доступен.
4. Перед обновлением уберите старые LAN-DLL и другие варианты GungeonTogether из этого профиля. Резервные копии храните за пределами `BepInEx/plugins`.
5. Нажмите **Start Modded**. Версия 0.2.2 автоматически включает LAN-режим при запуске из отдельного профиля менеджера.

При локальном импорте зависимости может потребоваться установить отдельно. На обоих ПК должна быть одна и та же сборка мода.

### ZIP с запускателем Windows

Для релиза, содержащего `GungeonTogether-LAN.exe`:

1. Распакуйте архив Windows в отдельную папку.
2. Закройте игру, включите Steam и откройте `GungeonTogether-LAN.exe` из распакованной папки.
3. Выберите папку игры, содержащую `EtG.exe`, и нажмите кнопку установки/запуска.
4. Запускатель предложит сохранить распознанные старые LAN-DLL в резервную папку и установить встроенную версию. Если BepInEx отсутствует, он скачает официальный пакет загрузчика и проверит контрольную сумму; для первой установки нужен интернет.
5. Последующие ручные LAN-запуски выполняйте через этот EXE. Версия мода встроена в запускатель, поэтому при обновлении мода обновляйте и запускатель.

Запускатель добавляет мод в папку игры и не обновляет профили менеджера.

## Подключение

1. Оба игрока запускают мод, входят в лобби и выбирают персонажа.
2. Нажмите **Ctrl+P**, чтобы открыть LAN-меню.
3. Хост нажимает **HOST**.
4. Клиент вводит LAN/Radmin IPv4 хоста, указывает такие же **TCP port** и **Session code**, затем нажимает **JOIN BY IP**.
5. После подключения хост нажимает **START SYNCHRONIZED DUNGEON**. Клиент загружается автоматически и получает управление Культистом после успешной проверки совпадения данжена.

TCP-порт по умолчанию — **27631**. Разрешите игре доступ через брандмауэр для используемой сети. Используйте доверенную локальную сеть или VPN: собственное шифрование TCP-соединения в моде отсутствует.

## Управление

Клиент использует обычные кнопки движения, прицеливания, стрельбы, переката, перезарядки, взаимодействия, холостого заряда и смены оружия. Паузой, картой и общими меню управляет хост. **Ctrl+P** повторно открывает меню подключения.

## Сохранения

LAN-прогресс отделён от обычного прогресса и хранится здесь:

`<папка игры>/BepInEx/GungeonTogetherLAN/dungeon-profile`

Обычные открытия и валюта автоматически не импортируются. Профили менеджера, использующие одну папку игры, разделяют этот LAN-прогресс: отдельный профиль модов сам по себе не создаёт отдельного игрового сохранения.

При настройках по умолчанию прямой запуск из Steam использует обычные сохранения и отключает LAN. Ручной запускатель явно выбирает LAN-сохранения. Перед изменением установки сохраните резервные копии обычного прогресса и LAN-папки.

Для генерации одинаковых комнат клиент временно использует состояние генерации хоста. При штатном отключении прежнее состояние клиента в памяти восстанавливается; восстановление после сбоя не гарантируется.

Дополнительная настройка: **Profile / SaveProfileMode** в `com.gungeontogether.lan.cfg`. `Auto` выбирает профиль по способу запуска, `Normal` отключает LAN, `LAN` явно выбирает LAN-сохранения. После изменения перезапустите игру. Для ручного запуска также поддерживается аргумент `--gt-lan-profile`.

## Совместимость и ограничения

- Другие Steam-варианты GungeonTogether и старые LAN-плагины несовместимы в одной установке/профиле. Для других сетевых модов используйте отдельные профили.
- Боевой звук клиента, некоторые эффекты и материалы, геометрия лучей, магазин и диалоги, а также изменение тайлов секретных стен реализованы не полностью.
- Повторная передача TCP-пакетов может задерживать состояние мира при плохом соединении.
- При разрыве соединения забег приостанавливается. Вернитесь в лобби и создайте новую сессию. Переподключение в активный забег и перенос хоста не реализованы.
- В диагностических запусках наблюдались ошибки инициализации персонажа и лобби.
- Два физических ПК через Radmin, полный забег, все боссы/предметы, обычные переходы после босса и сторонние сборки модов пока не проверены.

## Проверки

Игровая DLL 0.2.2 прошла **69 автоматических проверок транспорта, протокола и выбора сохранений**, а также **два прогона двух локальных процессов игры**. Проверялись совпадение первого и второго этажей, получение состояния клиентом, штатное движение Культиста, стрельба и урон. Выбор обычного/LAN-пути сохранений проверялся на копиях сохранений.

У тестового врага был выключен ИИ, а следующий этаж загружался штатной командой игры. Эти результаты не подтверждают полноценный сетевой забег. Подробности — в [VALIDATION.md](https://github.com/vladnow/GungeonTogether-LAN/blob/main/publication/VALIDATION.md).
