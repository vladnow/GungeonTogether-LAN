# Установка Gungeon Together LAN 0.3.4 alpha

Оба игрока должны использовать одинаковые файлы игры и одну сборку **0.3.4**. Она несовместима по сети с 0.3.3 и более ранними версиями.

1. Закройте игру. Сохраните резервные копии обычных и LAN-сохранений.
2. В Thunderstore Mod Manager выберите профиль Enter the Gungeon. Для первого теста используйте чистый профиль.
3. Установите BepInExPack EtG 5.4.2101. В профиле должен оставаться один сетевой мод. Уберите старые LAN-DLL и другие варианты GungeonTogether; копии храните вне BepInEx/plugins.
4. После появления 0.3.4 на сайте обновите установленный пакет. Если версия ещё не опубликована, используйте Settings → Import local mod и выберите GungeonTogether_LAN-0.3.4-Thunderstore.zip. Локальный импорт может требовать отдельной установки зависимости загрузчика.
5. Нажмите Start Modded. В LAN-меню должна отображаться версия **0.3.4** на обоих ПК.

Для разных сетевых модов используйте разные профили. Новый Windows-запускатель для этой версии не поставляется.

В лобби Esc закрывает сетевое меню, Ctrl+P открывает его. Хост выбирает HOST → CREATE ROOM. Друг выбирает JOIN, вводит IPv4 хоста, такой же порт и код комнаты, выбирает PLAYER TWO и подключается. Хост нажимает START RUN. Порт по умолчанию — TCP 27631. Для Radmin нужна общая виртуальная сеть.

Если меню само открылось и игра остановилась, сохраните полный текст под кнопкой, откройте DETAILS и сохраните LogOutput.log обоих игроков **до следующего запуска**. Файл находится в BepInEx внутри папки профиля. Закрытие меню не восстанавливает сессию с ошибкой; для нового подключения вернитесь в лобби.

LAN-прогресс: <папка игры>/BepInEx/GungeonTogetherLAN/dungeon-profile. Он отдельный от обычного, но общий для профилей менеджера с одной папкой игры. Обычные открытия и валюта не импортируются.

0.3.4 добавляет графический HUD гостя: сердца, броню, холостые, деньги, ключи, оружие/патроны и активный предмет. Добавлена передача звуков боя; громкость берётся из настроек игры каждого участника. Исправления камер и загрузки спрайтов слизней сохранены.

После обновления зайдите вдвоём в подземелье: у гостя должны появиться сердца и счётчики слева сверху, оружие с патронами слева снизу, активный предмет справа снизу. Проверьте выстрел, перезарядку, смену оружия, получение ключа и потерю здоровья. Для звука проверьте громкость SFX в настройках гостя и выстрелы обоих игроков. Если звука нет, сохраните логи обоих ПК до перезапуска; периодические строки GT_NETWORK теперь содержат счётчики audioCaptured/audioDispatched/audioFailed/audioDropped. Если пропал HUD, ищите GT_CLIENT_HUD. Не запускайте диагностические флаги со словом smoke для обычной игры: они намеренно отключают звук.

Полное прохождение не подтверждено; известная проблема карты четвёртого этажа с Sell Creep остаётся. HUD не воспроизводит весь инвентарь и магазин, музыка/фон и все особенности звуковых банков не синхронизированы полностью. Тесты были беззвучными: воспроизведение событий проверяется по вызовам движка, полнота звучания на слух ещё не проверена. Подробности — VALIDATION.md.
