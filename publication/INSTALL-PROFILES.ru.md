# Два мода — два профиля

Игра устанавливается один раз. Для переключения между нашей LAN-версией и Steam-модом Rec используются отдельные профили Thunderstore Mod Manager.

## После публикации

1. Создайте профиль **LAN**. Установите **GungeonTogether LAN 0.2.2** с сайта; BepInExPack EtG будет установлен как зависимость. Нажмите **Start Modded**. Отдельный EXE и параметр `--gt-lan-profile` для этого варианта не нужны.
2. Создайте профиль **3Player**. Установите **Rec / GungeonTogether_3Player** с его зависимостями. Запускайте этот профиль через **Start Modded**, подключайтесь через Steam по инструкции Rec.
3. Для переключения закройте игру, выберите другой профиль и снова нажмите **Start Modded**. Переустановка игры при каждом переключении не требуется.

Наш мод пока не опубликован. Сейчас подготовленный Thunderstore ZIP можно импортировать локально в профиль LAN через **Settings → Import local mod**. Выберите ZIP, при необходимости заполните поля названия/автора и подтвердите импорт. BepInExPack EtG 5.4.2101 при локальном импорте установите отдельно из каталога. Другу передайте такой же ZIP: локальная DLL не передаётся автоматически кодом экспорта профиля.

## Однократное обновление ручной 0.2.1

Закройте игру. В профиле `together`/LAN сохраните прежнюю `GungeonTogether.LAN-0.2.1-alpha.dll` за пределами `BepInEx/plugins`, затем импортируйте новую 0.2.2. Уберите старый `--gt-lan-profile` из дополнительных параметров менеджера — новая версия определяет профиль автоматически.

Не помещайте нашу DLL в профиль 3Player. Новая версия имеет собственный идентификатор и блокируется при обнаружении старого Steam GungeonTogether/старой LAN-версии в том же профиле. Это предотвращает совместную работу двух сетевых реализаций.

DLL, ранее установленную непосредственно в папку игры, сохраните за пределами `BepInEx/plugins`, например в `BepInEx/GungeonTogetherLAN/backups`. Старый ручной EXE повторно не запускайте для установки, переведённой на менеджер: он добавляет DLL обратно в основную папку игры.

## Если друг хочет переустановить игру

Переустановка допустима как однократная очистка, но не заменяет разделение профилей. Ручные файлы модов могут остаться, а папки профилей менеджера хранятся отдельно от игры и не исчезают при её удалении в Steam.

1. Закройте игру и скопируйте сохранения в резервную папку: `%USERPROFILE%\AppData\LocalLow\Dodge Roll\Enter the Gungeon` и `BepInEx\GungeonTogetherLAN\dungeon-profile` внутри папки игры. Первая папка содержит обычный прогресс, вторая — наш LAN-прогресс.
2. Удалите игру через Steam. Если прежняя папка `Enter the Gungeon` осталась, переместите её целиком в резервную папку вне `steamapps\common`. Так сохранятся остатки ручной установки, а новая установка получит чистую папку. Не удаляйте папку сохранений Windows.
3. Установите игру снова и проверьте обычные сохранения запуском из Steam.
4. В менеджере создайте свежие профили **LAN** и **3Player**, установите моды по отдельности, как описано выше. Старые профили автоматически не исчезают при удалении игры: их не нужно переносить в новую папку Steam.
5. Если нужен прежний LAN-прогресс, после закрытия игры восстановите только резервную `dungeon-profile` на прежнее место. Не возвращайте старую DLL/EXE вместе с ней.

Ошибка **Failed to start modded / Не удаётся найти указанный файл** обычно требует отдельной проверки путей менеджера. На этом ПК Steam находится в `F:\programi\Steam`, игра — в `F:\programi\Steam\steamapps\common\Enter the Gungeon`, исполняемый файл — `EtG.exe`. У друга пути могут быть другими. Публикация мода сама по себе неверный путь к Steam/игре не исправляет.

## Сохранения и ограничения

Профили разделяют моды и настройки. LAN-прогресс нашего мода отделён от обычного прогресса и хранится в папке игры. Нормальные открытия и деньги автоматически в LAN не импортируются. Мод Rec следует своей модели сохранений; отдельный профиль менеджера сам по себе не создаёт отдельного игрового сохранения.

Это альфа. Удалённые выстрелы и смена этажа проверяются в двух локальных процессах; полный прогон на двух физических ПК через Radmin, все боссы/предметы и модпаки пока не подтверждены. Для LAN сначала используйте только наш мод на обоих ПК.
