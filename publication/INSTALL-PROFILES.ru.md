# Установка Gungeon Together LAN 0.3.0 alpha

Оба игрока должны использовать одинаковую версию игры и мода. Для начала используйте чистый профиль с одним сетевым модом. Версия 0.3.0 несовместима по сети с 0.2.x.

## Без менеджера

Распакуйте Windows ZIP в отдельную папку. Закройте игру, запустите Steam, откройте GungeonTogether-LAN.exe и выберите папку с EtG.exe. Запускатель предложит сохранить распознанные старые LAN-DLL в резервную папку, установит встроенную 0.3.0 и запустит отдельный LAN-профиль. Если BepInEx отсутствует, понадобится интернет для скачивания официального загрузчика с проверкой контрольной суммы. Запускатель устанавливает мод в папку игры; профили менеджера он не обновляет.

## Через менеджер

Создайте чистый профиль и установите BepInExPack EtG 5.4.2101. Уберите прежние LAN-DLL и другие GungeonTogether из этого профиля, сохранив резервные копии за пределами BepInEx/plugins. Импортируйте GungeonTogether_LAN-0.3.0-Thunderstore.zip через Settings → Import local mod, затем нажмите Start Modded. При ручной установке DLL поместите её в BepInEx/plugins/GungeonTogetherLAN внутри профиля. В профиле должна остаться ровно одна LAN-DLL.

## Подключение

1. Войдите в лобби и выберите местного героя. Esc закрывает LAN-меню, Ctrl+P открывает.
2. Хост: HOST → CREATE ROOM. Адрес приёма 0.0.0.0 подходит для всех адаптеров.
3. Клиент: JOIN → IPv4 хоста, одинаковые порт и код комнаты. Порт по умолчанию — 27631.
4. Клиент выбирает героя стрелками в блоке PLAYER TWO: Культист, Пилот, Десантник, Осуждённая или Охотница. Этот выбор относится к забегу и не меняет местного героя в лобби. Менять выбор можно до начала забега.
5. Клиент нажимает JOIN BY IP, затем хост нажимает START RUN.

## Сохранения и ограничения

LAN-прогресс хранится в <папка игры>/BepInEx/GungeonTogetherLAN/dungeon-profile отдельно от обычного. Профили менеджера с одной папкой игры используют общую папку LAN-сохранений. Перед обновлением сохраните резервную копию LAN-прогресса.

Интерполяция добавляет 120 мс задержки отображения. Долгие сетевые остановки и штатное ограничение расстояния между игроками всё ещё могут приводить к коррекциям. Полный забег, все предметы, особые финалы и другие модпаки не проверены. Для других сетевых вариантов GungeonTogether используйте отдельные профили.

Известная проблема версии 0.3.0: на четвёртом этаже воспроизведено расхождение карты, при котором проверка мода останавливает забег. Сборка предназначена для тестирования ранних этажей; пятый этаж в продолженном тесте не достигнут.

Для сообщения об ошибке сохраните LogOutput.log обоих игроков, укажите выбранных героев и последнее действие. Подробности — в README.ru.md и VALIDATION.md.
