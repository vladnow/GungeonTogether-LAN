# Установка Gungeon Together LAN 0.3.2 alpha

Оба игрока должны использовать одинаковые файлы игры и одну сборку **0.3.2**. Она несовместима по сети с 0.3.1 и более ранними версиями.

1. Закройте игру. Сохраните резервные копии обычных и LAN-сохранений.
2. В Thunderstore Mod Manager выберите профиль Enter the Gungeon. Для первого теста используйте чистый профиль.
3. Установите BepInExPack EtG 5.4.2101. В профиле должен оставаться один сетевой мод. Уберите старые LAN-DLL и другие варианты GungeonTogether; копии храните вне BepInEx/plugins.
4. После появления 0.3.2 на сайте обновите установленный пакет. Если версия ещё не опубликована, используйте Settings → Import local mod и выберите GungeonTogether_LAN-0.3.2-Thunderstore.zip. Локальный импорт может требовать отдельной установки зависимости загрузчика.
5. Нажмите Start Modded. В LAN-меню должна отображаться версия **0.3.2** на обоих ПК.

Для разных сетевых модов используйте разные профили. Новый Windows-запускатель для этой версии не поставляется.

В лобби Esc закрывает сетевое меню, Ctrl+P открывает его. Хост выбирает HOST → CREATE ROOM. Друг выбирает JOIN, вводит IPv4 хоста, такой же порт и код комнаты, выбирает PLAYER TWO и подключается. Хост нажимает START RUN. Порт по умолчанию — TCP 27631. Для Radmin нужна общая виртуальная сеть.

Если меню само открылось и игра остановилась, сохраните полный текст под кнопкой, откройте DETAILS и сохраните LogOutput.log обоих игроков **до следующего запуска**. Файл находится в BepInEx внутри папки профиля. Закрытие меню не восстанавливает сессию с ошибкой; для нового подключения вернитесь в лобби.

LAN-прогресс: <папка игры>/BepInEx/GungeonTogetherLAN/dungeon-profile. Он отдельный от обычного, но общий для профилей менеджера с одной папкой игры. Обычные открытия и валюта не импортируются.

0.3.2 исправляет подтверждённую остановку при загрузке спрайтов слизней. Полное прохождение не подтверждено; известная проблема карты четвёртого этажа с Sell Creep остаётся. Клиентские звук, часть эффектов и интерфейсов неполны. Подробности проверок — VALIDATION.md.
