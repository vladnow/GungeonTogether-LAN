# 0.3.7 validation evidence

The sanitized native-summary.json records the exact tested runtime and case results. Raw logs, test plugins, host generation envelopes, screenshots and local save fixtures remain private under work/ and are not distributed.

Native processes use private game copies and isolated save/loader profiles, -nosound, paused audio listener, intercepted audio playback, 800x600 windowed WS_EX_NOACTIVATE mode, an unconstrained cursor and background simulation. No Computer Use or foreground keyboard/mouse automation is used.

Feedback scenarios exercise original HUD widgets, distinct shoot/interact physical controls, an ordinary door with separated players, a locked door, real native textboxes and conversation buttons, poison/fire cells and meshes, fire particles, host damage and guest damage shader/material/audio dispatch. They also retain the base native remote movement/fire/projectile damage and two-floor layout handshake.

The responsiveness case simulates short walk pulses WITH WASD's additional native menu-navigation bits. It measures time from an input sample to 0.0625 game units of displayed displacement in a local native client. It is not a real keyboard/input-to-photon test or a physical-PC/Radmin measurement.

A separate regression case covers native secret-room reveal, guest equipment-page icons, shared consumables, forced ghost persistence and a native resurrection call. It does not establish a complete natural death/boss/chest cycle.

The reported dark halo is addressed through native collider/light-position updates; a remote visual comparison is still outstanding. The ordinary-door proximity gate was identified, but arbitrary room-transition locks are not all reproduced. Full campaign completion and the fourth-floor Sell Creep mismatch remain unresolved. Sound output is disabled, so audible quality is unverified. Fresh mod-manager import and remote upload/publication are separate checks.
